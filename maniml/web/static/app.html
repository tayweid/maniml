Set up ManimLive

The interface installs from the web. Your scenes and Python engine stay on this computer.

1

Install the web app

Use your browser’s install icon or menu to add ManimLive to your applications.

Installed as an app.
2

Install the local engine and app

Once, in a terminal, activate the Python environment you use for Manim, then run:

python -m pip install "git+https://github.com/tayweid/maniml.git" && maniml install-desktop

After this one-time macOS setup, open a scene from Finder or the app—no terminal needed.

3

Open a scene

Open ManimLive from Applications, choose Open With → ManimLive on a Python file, or use Open… above while the local app is connected.

The desktop launcher performs the explicit local action that a website is not allowed to perform.
