ManimLive

preview — the app runs on your machine

Live manim, with the animation you are editing already on screen.

A ManimCE-compatible API on an OpenGL backend, with checkpoints at every play(): arrow through your animations, save the file and watch only what changed replay, and render the scene in the browser with its own GPU.

This page is a preview

ManimLive runs Python — your scenes, your packages, your files — so it runs on your own computer, not here. Nothing on this page connects to it. Two commands and you have the real thing:

1
Install it. 
python -m pip install --upgrade --force-reinstall --no-cache-dir "maniml @ git+https://github.com/tayweid/maniml.git"
2
Open it. This starts the engine and opens the app in your browser at http://localhost:8685. 
maniml app ~/Projects

From there the app itself offers to install as a desktop app — its own icon, its own window, and double-clicking a .py file opens it. That offer belongs to the local app rather than this page, so only one ManimLive ever owns your Python files.

What you get

  • Checkpoints at every play(). Arrow keys step forward through your animations, re-running each from source, or jump back instantly.
  • Hot reload that replays only what changed. Save the file and edited animations replay from the last good checkpoint.
  • Click a mobject to find it. It prints the variable name; drag it and you get a paste-ready move_to([x, y, z]).
  • The browser renders it. Scenes draw through WebGPU on your own GPU, pixel-faithful to the native renderer.
  • Bake a scene to share. --export writes a self-contained page students can scrub through, with no Python anywhere.
ManimLive is alpha software, built from 3Blue1Brown's ManimGL lineage with code adapted from ManimCommunity's Manim. It is not an official ManimCommunity project. Source on GitHub.
